# Искорка

Танцующий домик: поёт на сцене, собирает монетки и строит модульные домики.

**Играть:** [https://serega40in.github.io/silver-earth-wood-drum/](https://serega40in.github.io/silver-earth-wood-drum/)

Статическая версия для GitHub Pages лежит в папке `docs/`.

## Управление

- **WASD / стрелки** — бег и поворот
- **Пробел** — реверанс
- **1–8** — модули стройки
- **R** — поворот модуля
- **M** — звук
- На телефоне — джойстик слева

## GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` → Folder: `/docs` → Save.
